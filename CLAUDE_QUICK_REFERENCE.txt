📊 MODES EXPLAINED
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  OLLAMA-ONLY (Local):
    • All requests → Local Ollama
    • Speed: Instant (100-500ms)
    • Cost: FREE
    • Quality: Good for patterns and suggestions
    • Use: Offline, no API costs, quick advice
  
  HYBRID (Smart Routing):
    • Simple tasks → Ollama (instant)
    • Complex tasks → Claude (quality)
    • Speed: ~1-3 seconds
    • Cost: ~$0.002 per request (10% Claude)
    • Quality: Best quality overall
    • Use: Strategic planning, important decisions

🆘 TROUBLESHOOTING

🧠 ASK CLAUDE DIRECTLY (Bypass Router)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  Use when: You want guaranteed Claude quality, strategic questions

  FROM COMMAND LINE:
    claude-ask "What's your advice on this?"
    claude-gtd ask "Strategic question here"
  
  FROM WIZARD:
    gtd-wizard → 11) Get advice → 8) Quick Claude → 5) Ask Claude directly

  EXAMPLES:
    claude-ask "Help me think through this decision"
    claude-ask "What patterns do you see in my productivity?"
    claude-ask "What's the best way to approach this problem?"

  DIFFERENCE FROM ROUTER:
    Router:  Intelligent routing (Ollama or Claude)
             ~ Free-fast, some requests routed to Ollama
    
    Ask:     Always Claude
             ~ Best quality, always costs, always 1-3 seconds
