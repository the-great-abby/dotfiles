# Example Skill

This is an example Agent Skill that demonstrates the SKILL.md format.

## When to Use

Use this skill as a template when creating new skills. It shows:
- YAML frontmatter for metadata
- Markdown instructions
- How to structure skills

## How It Works

Skills can contain:
- **Instructions**: Detailed markdown in this file
- **Scripts**: Executable scripts in the `scripts/` directory
- **Templates**: Template files in the `templates/` directory
- **Resources**: Supporting files in the `resources/` directory

## Usage

This example skill doesn't perform any action, but demonstrates the structure that real skills should follow.

## Parameters

No parameters required for this example skill.
