## 🚀 How to Use

### Check Your Stats (Right Now!):
```bash
gtd-log-stats
```

### Get Weekly Report:
```bash
gtd-weekly-progress
```

### Log an Entry (Triggers Milestone Check):
```bash
log "my entry"
# or
addInfoToDailyLog "my entry"
```
